## AI Code Evaluation Strengths

I approach AI-generated code and technical responses by checking:

1. Does the solution actually satisfy the user request?
2. Is the code logically correct?
3. Are important edge cases handled?
4. Are assumptions stated clearly?
5. Is the implementation maintainable?
6. Are there security, privacy, or data-handling risks?
7. Are tests or validation steps appropriate?
8. Is the explanation technically accurate and useful?

This is the same mindset I apply across my own projects: define the expected behavior, inspect the implementation, check the failure modes, verify with evidence, and explain the result clearly.
